## dembrandt-skills

- Repository: https://github.com/dembrandt/dembrandt-skills
- Pinned revision: `97b20315b064b02da6a143c4a476b7ce91fc613c` (2026-11-24)
- Licence: MIT, Copyright (c) 2026 Dembrandt

The six new reference files — `SURFACES.md`, `COMPOSITION.md`, `COMPONENTS.md`, `COLOUR-AND-TYPE.md`, `ACCESSIBILITY.md`, `PERFORMANCE.md` — condense rules from that library's per-topic skills (layout paradigms, information architecture, marketing versus product, UI hierarchy, gestalt, surface separation, elevation, component family, button states, forms, data display, tabs, overlays, notifications, scroll areas, sticky elements, colour derivation, type scales, WCAG, web vitals, loading states). Nothing is copied verbatim: each file states the rule in this skill's voice, with the reason, and drops the per-skill scaffolding. The simplifying rule across all six is that a rule already stated in `SKILL.md` stays there; the reference adds depth rather than repeating it.

Their skills are not installed alongside this one. Two design processes in one session compete for the same decisions, and this skill's twelve checks are the spine here.
